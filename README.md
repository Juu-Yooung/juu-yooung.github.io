## Deploying the update

No build step or package installation is required.

1. Extract the release ZIP.
2. Copy its contents into the repository's configured GitHub Pages publishing directory, preserving filenames and the images/ folder structure.
3. Include the hidden .nojekyll file. Replace matching website files.
4. Keep the repository's existing Pages configuration, workflow files, and custom-domain settings.
5. Commit the files and let the existing deployment process complete.

The ZIP itself is a delivery archive; deploy the extracted files.
